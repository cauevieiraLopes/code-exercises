# 🔢 Gerador de Sequência de Fibonacci em Java

Aplicação de terminal em Java criada para gerar a **Sequência de Fibonacci** até um valor limite estipulado pelo usuário. O projeto explora o uso de estruturas de repetição, lógica de troca de variáveis e tipos primitivos de maior capacidade.

---

## 🎯 Objetivos de Aprendizado

- **Lógica da Sequência de Fibonacci:** Implementação da regra onde cada termo subsequente é a soma dos dois anteriores ($F_n = F_{n-1} + F_{n-2}$).
- **Validação de Entrada (`do-while`):** Garantia de que o limite digitado seja um número válido e não negativo.
- **Estrutura de Repetição (`while`):** Controle da exibição dos valores até atingir o limite estipulado.
- **Capacidade de Armazenamento (`long`):** Uso do tipo primitivo `long` para evitar estouro de memória (*overflow*) em números muito grandes.

---

## 🛠️ Como Executar

1. Certifique-se de ter o **JDK 8+** instalado.
2. Navegue até a pasta `src` no terminal e compile o arquivo:
   ```bash
   javac br/com/fibonacci/main/Main.java
   ```
3. Execute o programa:
  ```bash
  java br.com.fibonacci.main.Main
  ```
